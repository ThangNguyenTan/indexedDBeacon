### Description (Copy and paste into Description box)
```markdown
IndexedDBeacon is the modern, high-performance IndexedDB manager and inspector built directly into Chrome Developer Tools with ZERO permissions required.

If you have ever tried inspecting or debugging IndexedDB using Chrome's built-in DevTools (Application > Storage > IndexedDB), you know how frustrating it is:
• You cannot edit nested JSON records or objects in place.
• You cannot insert new records or duplicate existing ones.
• Complex types like BigInt, Date, and binary Blobs are truncated or unreadable.
• The panel doesn't notify you when background data changes.
• There is no smooth search, sorting, or flexible export/import tooling.

IndexedDBeacon solves all of these limitations with a dedicated, professional DevTools panel engineered for developer productivity.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚡ KEY FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔒 100% PRIVATE WITH ZERO PERMISSIONS
• Requires NO host permissions (<all_urls>), NO background workers, and NO external tracking.
• When installing, Chrome confirms: "It can: No permissions requested".
• 100% of data inspection happens locally inside your DevTools panel.

✏️ FULL IN-PLACE CRUD & NESTED JSON EDITOR
• Modify values directly in the built-in JSON editor with live syntax linting, prettifying, and Ctrl+Enter hotkey save.
• Insert new records with template scaffolds (User, Product, Custom).
• 1-Click "Duplicate Record" action: clones existing records and auto-suggests non-colliding keys for rapid test fixture creation.
• Batch select and delete records with a single click.

🪟 DETACHED STANDALONE WINDOW ("POP OUT")
• Need full screen space to test your responsive web application?
• Click "Pop out" to run IndexedDBeacon in a separate, dedicated operating system window (just like Redux DevTools).
• Dock back to the DevTools panel at any time.

⌨️ DESKTOP-GRADE KEYBOARD NAVIGATION
• Browse records with Arrow Up (↑) and Arrow Down (↓) keys with live inspector updates.
• Jump to first/last records with Home / End.
• Press Delete to instantly prompt record deletion.
• Press Ctrl+F to focus the search box; press Escape to clear and blur.

📦 FIRST-CLASS SUPPORT FOR COMPLEX TYPES
• BigInt values preserved losslessly (e.g. 9450000000000n).
• Native Date objects rendered with formatted timestamps.
• Map and Set collections displayed with item counts and entries.
• Binary Blobs and Files: inline image previews (PNG, JPEG, SVG) and audio playback with 1-click download buttons.

🔍 ADVANCED QUERYING & FILTERING
• Query by Primary Key or any secondary Index.
• Toggle sort order between Ascending and Descending.
• Filter with IDBKeyRange (Exact key, Lower Bound, Upper Bound, Between).
• Instant live search with an inline clear (×) button.

📤 1-CLICK EXPORT & IMPORT
• Export filtered view or entire stores to JSON (Array of values or Key-Value pairs) or flattened CSV.
• Copy export payload directly to clipboard or download as a file.
• Drag-and-drop JSON import with "Put (Upsert)" or "Add (Insert)" modes.

🔄 PASSIVE STALE DATA NOTIFICATION
• Zero battery-draining polling loops: non-invasively observes IndexedDB mutations.
• An amber "Data Stale · Refresh" indicator appears when background scripts write data, allowing you to reload with a single click.

🎨 SEAMLESS DEVTOOLS THEMING
• Automatically syncs with Chrome DevTools Dark or Light mode.
• Features an instant 1-click theme toggle switch.

3. Press F12 (or Ctrl+Shift+I / Cmd+Option+I) to open Chrome Developer Tools.
4. Select the "IndexedDBeacon" tab in the top DevTools tab bar.
5. Expand any database in the sidebar to inspect, query, and edit stores!
```
